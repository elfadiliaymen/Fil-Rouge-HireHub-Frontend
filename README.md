# HireHub Frontend

Frontend React de la plateforme de recrutement **HireHub**.

## Modules

- **Utilisateurs** - gestion des candidats, recruteurs et administrateurs.
- **CV** - upload, consultation et gestion des CV.
- **Candidatures** - suivi des candidatures et de leurs statuts.
- **Offres d'emploi** - publication et gestion des offres.
- **Entretiens** - planification et gestion des entretiens.

## Rôles

- `ADMIN`
- `RECRUTEUR`
- `CANDIDAT`

## Installation

```bash
npm install
npm run dev
```

Le backend API est accessible sur `http://localhost:8090/api`.
